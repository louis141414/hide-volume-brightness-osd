# Hide Volume & Brightness OSD

A fast and lightweight **Windhawk** mod that selectively hides the Windows on-screen displays (OSDs) for volume, brightness, media controls and more.

Perfect if you want a cleaner desktop without the floating bars that appear when you change volume or brightness.

## Features

- Hide **Volume OSD**
- Hide **Brightness OSD**
- Hide **Media / Now Playing** flyout
- Optionally hide other system OSDs
- Extremely low CPU usage
- Instant reaction (configurable poll interval)
- Works on **Windows 10** and **Windows 11**

## Installation

1. Install [Windhawk](https://windhawk.net/) if you don't have it yet.
2. Open Windhawk → **Create a new mod**.
3. Copy the contents of [`hide-volume-brightness-osd.wh.cpp`](hide-volume-brightness-osd.wh.cpp) and paste it into the editor.
4. Click **Compile mod**.
5. Enable the mod and configure the settings.

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| **Hide Volume OSD** | On | Hides the volume bar |
| **Hide Brightness OSD** | On | Hides the brightness indicator |
| **Hide Media / Now Playing flyout** | On | Hides the larger media controls |
| **Hide other system OSDs** | Off | Also tries to hide less common ones |
| **Check interval (ms)** | 120 | How often it checks (lower = faster) |
